# Design system

## Direction

Guardia uses a black and charcoal interface with precise red accents. The visual reference is a dark, faceted surface crossed by vivid red lines; the interface translates that into a quiet, angular mark and red signals rather than placing an image or busy texture behind clinical data.

## Color

- Ground: `#080808`
- Main surface: `#121212`
- Raised surface: `#202020`
- Main text: `#f5f5f5`
- Secondary text: `#b8b8b8`
- Brand red: `#ff5266`
- Primary action: `#d82e43`
- Clinical statuses retain distinct semantic colors: green for fit, amber for pending, and red for due or restricted.

## Typography and components

- Geist is the interface typeface.
- Tables and forms use restrained dark surfaces, visible control outlines, and high-contrast text.
- Red marks actions, active navigation, and clinically relevant follow-up; it is not used as a broad decorative fill.
- Use the angular Guardia mark as the geometric reference point. Do not use the supplied reference image as a page background.
